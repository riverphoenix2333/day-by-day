# Day by Day

每天做一点，看看自己做到了什么。Day by Day 是一款个人习惯记录应用，支持 Windows 和 Android。打开就能离线使用。想在两台设备之间接着记，可以连接你自己的 GitHub 私有仓库。

## 下载 1.0

| 平台 | 下载 | 怎么打开 |
| --- | --- | --- |
| Windows 64 位 | [下载便携 ZIP](https://github.com/riverphoenix2333/day-by-day/releases/download/v1.0.0/Day-by-Day-1.0-Windows-x64.zip) | 完整解压，进入 `win-unpacked`，双击 `Day by Day.exe` |
| Android 7.0 或更新版本 | [下载 APK](https://github.com/riverphoenix2333/day-by-day/releases/download/v1.0.0/Day-by-Day-1.0-Android.apk) | 在手机上打开 APK，按系统提示安装 |

[查看发布页和 SHA-256 校验值](https://github.com/riverphoenix2333/day-by-day/releases/tag/v1.0.0)

- **Windows 桌面图标**：右键解压目录里的 `Day by Day.exe`，选择「显示更多选项 → 发送到 → 桌面快捷方式」。启动时双击快捷方式，程序和它的依赖文件放在原解压目录。Windows 版未做代码签名，首次打开时系统可能提示发布者未知。
- **Android 安装**：如果系统提示当前浏览器或文件管理器没有安装权限，按提示为当前来源开启「允许安装未知应用」。安装结束后可以关回去。旧用户可用同签名的 APK 覆盖更新，更新前可先导出完整 JSON 备份。

## 从一个习惯开始

1. 打开 **Today**，点「新习惯」写下一个具体动作，例如「晚饭后读两页」。也可以从「习惯资料库」的 107 条资料里挑一项加入计划。想当天开始时，创建时勾选加入今天。
2. 在「今天的习惯」标记「完成」「未完成」或「不适用」。可给每项写一句自我评价。每项有自己的蓝色进度条，累计 21 个完成日后会归入「已养成习惯」。漏打卡、休息或不适用的日期不推进。
3. 在清单下方写当天笔记、选精力评分并完成复盘。通过日期切换可以补记；从 Today 移除习惯后，过去的记录仍可在「仪表盘」查看。

| 入口 | 可以做什么 |
| --- | --- |
| 每日轮动 | 阅读会轮换的情境技巧和观察，也可以添加自己的提醒。轮动无需打卡。 |
| 习惯资料库 | 查看解释和原视频出处、管理计划和执行频率、写下想养成习惯的理由。Today 对应条目可以展开查看理由。 |
| Today · 每日一言 | 随日期阅读名言。外国名言上英下中，点击「了解 ta」查看人物简介。 |
| 仪表盘 | 回看历史、完成情况和趋势建议。 |
| 数据与来源 | 导出完整 JSON 备份或 CSV，导入 JSON 备份，配置可选的 GitHub 同步。 |

## 在电脑和手机之间同步

用自己的 GitHub 账号建立一个私有仓库，两台设备连接同一仓库。打卡、计划、自我评价、笔记和精力评分等会同步。GitHub 会保存这些记录及其提交历史，请让仓库保持私有。

- [一步一步配置 GitHub 同步](docs/github-sync.md)
- [Windows 懒人配置 · 可复制给 Codex 的提示词](docs/codex-sync-prompt.md)
