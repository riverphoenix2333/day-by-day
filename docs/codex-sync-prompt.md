# Windows 懒人配置提示词

复制下方整段到 Windows 上的 Codex。准备好 Day by Day 和自己的 GitHub 账号。GitHub 登录、二次验证、令牌生成和粘贴由你本人操作。如果 Codex 无法操作界面，让它按 [手动教程](github-sync.md) 逐步带你完成。

```text
帮我为 Windows 上的 Day by Day 1.0 配置 GitHub 私有同步，并带我验证安卓也能同步。使用我自己的 GitHub 账号。请全程先说明我需要手动做的步骤，不要自动弹出浏览器或应用窗口。

1. 核对当前 GitHub 账号。用已授权且可用的 GitHub 工具，在我个人账号下创建名为 habit-journal-sync 的私有仓库，并用 README 初始化。若同名仓库已存在，只核对可见性和默认分支。只有在我确认它就是已有的 Day by Day 同步仓库后才复用。若同名仓库为公开或另有用途，暂停并让我另选私有仓库名，不改动现有仓库。
2. 引导我打开 https://github.com/settings/personal-access-tokens/new。让我选择自己的账号、设置有效期、选择 Only select repositories，并且只选上一步的私有仓库。仓库权限仅设 Contents 为 Read and write，保留 GitHub 默认只读的 Metadata。身份确认和生成令牌由我手动完成。不要读取令牌、剪贴板、密码或验证码，也不要让我把它们发到聊天里。
3. 引导我打开 Day by Day → 数据与来源 → GitHub 同步 → 连接私有仓库。如果我已打开应用且你有安全的界面操作能力，可协助填写仓库所有者、仓库名称和分支。访问令牌由我本人直接粘贴到应用中，并由我点击保存并连接。没有界面操作能力时，把应填的三个非敏感值列给我。不要直接修改应用的本机存储。
4. 等 Windows 显示已同步。然后提示我在安卓填写同一仓库、同一分支及该仓库的细粒度读写令牌。带我在 Windows 写测试笔记、在安卓核对并修改，再回 Windows 点击立即同步核对。若失败，保留现有记录，按同步状态排查，不要清空或覆盖任何数据。
5. 最后只汇报仓库所有者、仓库名、分支和测试结果。不要在消息、脚本、截图或文件里留下令牌或个人打卡内容。
```
